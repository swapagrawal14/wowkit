# Product workbench
Best for: developer tools and workflow software.
Lead with the workflow problem and a real product example. Follow with a
three-step walkthrough, integration constraints, transparent pricing (only if
provided), FAQs, and one actionable CTA. Use a small monospace label system,
strong grid and high-contrast surfaces. Any simulated terminal must be labeled
as an example. Do not invent live functionality or API responses.
